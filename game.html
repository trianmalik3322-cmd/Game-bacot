📱 Cara Main Offline di HP

1
Install Termux dari F-Droid: f-droid.org
2
Buka Termux, ketik:
pkg update -y && pkg install nodejs -y
3
Kasih akses storage:
termux-setup-storage
4
Masuk folder project:
cd /sdcard/Download/Update-version-change
5
Build game:
npm install && npm run build
6
Buka di Chrome:
file:///sdcard/.../dist/index.html
